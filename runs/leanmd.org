Next session:
1. =jube continue leanmd_bench --id 0= until 3/3 done.
2. Confirm each workpackage's work directory (under
   =leanmd_bench/000000/...=, see the =dir:= line above) contains a
   =trace_<SLURM_JOBID>_<SLURM_NNODES>_<SLURM_NTASKS>.tar.gz=.
3. Unpack one and check it holds one =.sts=, one =.projrc=, and one
   =.<pe>.log= (or =.log.gz=) per rank — that's the complete file set
   Charm's =-tracemode projections= writes (verified against
   =deps/charm/src/ck-perf/trace-projections.C=), so if all three are
   present the trace is usable by the analysis tool.

Traces are intentionally left where JUBE puts them — nothing copies
or indexes them elsewhere, so this directory (reported by =jube run=/
=jube info=) is the actual path to pull them from.
